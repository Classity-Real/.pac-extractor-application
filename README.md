# What is this?
PExt (Originally .pac-extractor) is the tool made for unisoc devices to extract the device firmware using binaries and pasting it to “PExt/Extracted”

# What’s the available format and what status?
Must be on “.pac” like example “x6525.pac”
it should contain like super.img, vendor_boot, boot, and more. As for right now im not ready to make it yet since no code yet
